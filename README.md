# Onmyoji Auto — bản phát hành

Repo này chỉ chứa file cài đặt. Mã nguồn không nằm ở đây.

## Tải về

Vào [Releases](../../releases/latest) và tải `OnmyojiAuto-<phiên bản>.exe`.

Mở file đó lên là chạy — không cần cài Python hay gì thêm.

## Cập nhật

App tự kiểm tra bản mới mỗi lần khởi động. Có bản mới thì hiện một dải trên
đầu cửa sổ: bấm **Cập nhật**, đợi tải xong, rồi bấm **Khởi động lại để cài**.
Không cần quay lại trang này.

## Windows báo "Windows protected your PC"

File chưa mua chữ ký số nên SmartScreen cảnh báo. Bấm **More info** →
**Run anyway**.
